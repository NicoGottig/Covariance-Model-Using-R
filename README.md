## Proyecto Final de "Modelos Lineales"

En este proyecto se emplean modelos lineales para explorar relaciones entre indicadores económicos clave y el crecimiento económico. Específicamente, el análisis se centra en:

- **Porcentaje de Población Económicamente Activa**: Población entre 15 y 64 años sobre el total.
- **Especialización en Exportaciones de Media y Alta Tecnología**: Medido como porcentaje del total de exportaciones de manufactura.
- **Crecimiento Económico**: Medido como PBI per cápita en dólares, ajustado a precios de 2015.

### Datos y Metodología

- **Fuentes de Datos**: Se descargaron y procesaron tres bases de datos del Banco Mundial para el año 2016.
- **Análisis**: Tras la realización de un Análisis Exploratorio de Datos (EDA), se estimó la varianza y los elementos significativos para su explicación. El objetivo principal no fue la predicción, sino la inferencia de relaciones.
- **Limitaciones**: Las conclusiones no son definitorias, ya que se realizaron modificaciones en la variable respuesta para cumplir con las consignas del proyecto. Además, la inferencia se limita al año 2016, por lo que sería necesario utilizar modelos longitudinales para obtener resultados más precisos y definitivos.

# Covariance Model Using R

## Final Project for "Linear Models"

This project uses linear models to explore relationships between key economic indicators and economic growth. Specifically, the analysis focuses on:

- **Percentage of Economically Active Population**: People aged between 15 and 64 as a proportion of the total population.
- **Specialization in Medium and High Technology Exports**: Measured as a percentage of total manufacturing exports.
- **Economic Growth**: Measured as GDP per capita in USD, adjusted to 2015 prices.

### Data and Methodology

- **Data Sources**: Three datasets from the World Bank were downloaded and processed for the year 2016.
- **Analysis**: After conducting Exploratory Data Analysis (EDA), variance and the significant elements influencing it were estimated. The primary aim was not to predict but to infer relationships.
- **Limitations**: The conclusions are not definitive, as adjustments were made to the response variable to meet specific project requirements. Furthermore, the inference is limited to the year 2016, and longitudinal models would be needed for more precise and definitive conclusions.
